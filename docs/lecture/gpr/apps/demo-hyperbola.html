Fit curve with its apex locked to the observed apex $(x_0, t_0)$: $t(x)=\sqrt{t_0^2+\left(\dfrac{2(x-x_0)}{v}\right)^2}$. Only the limbs change with $v$: too slow a velocity makes them too steep, too fast makes them too flat. Implied depth $d=v\,t_0/2$. Relative permittivity from velocity: $\varepsilon_r=\left(\dfrac{c}{v}\right)^2$ with $c=0.30$ m/ns.
Model assumptionsWhat this simulation simplifies
  • The radargram holds one point diffractor in a uniform medium, recorded with a zero-offset antenna: t(x) = 2√(d² + (x − x₀)²)/v, the same law the fit curve uses.
  • The fit assumes constant velocity, a point-like target, zero time offset, and negligible antenna separation.
  • The reflection is drawn with the same strength at every antenna position: there is no geometric spreading, attenuation, antenna pattern, or noise, so the limbs end only where they leave the 60 ns window.
  • εᵣ = (c/v)² assumes a low-loss, non-magnetic medium.
