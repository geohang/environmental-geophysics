2. Peters' Half-Slope Method

A graphical method specifically for dykes using the anomaly slope.

Depth ≈ d / 1.2 (thin dike)

Steps to Calculate:

  1. Draw a tangent at the point of maximum slope (inflection point).
  2. Construct a line with exactly half the slope of the tangent.
  3. Find where this "half-slope" line is tangent to the anomaly curve at two points (one high, one low).
  4. Measure the horizontal distance 'd' between these two points.
  5. Apply the formula: Z ≈ d / 1.2

Peters' factor ranges from about 1.2 for thin dikes to about 2.0 for thick dikes; 1.6 is a common compromise. For the thin-dike curve drawn here, z ≈ d/1.2. Treat the result as approximate depth to the top.

3. Reduction to the Pole (RTP)

Correcting the latitude effect to center anomalies over their sources.

Filter: I → 90° (Pole)

Problem & Solution

Problem: At mid-latitudes, induction causes dipoles. The peak is shifted away from the actual source.

Solution (RTP): A mathematical filter simulates measuring the data at the magnetic pole.

Ideal induced-only result: anomalies become more symmetric and centered.

RTP can be unstable at low magnetic inclination and can misplace sources when remanent magnetization is important.

Status: Raw Data (Asymmetric)

Both curves come from the same induced dipole at 10 m depth. For a purely induced source, the RTP result is the anomaly the same body would produce at I = 90°.

  • Sections 1 and 2 draw the same bell-shaped curve, proportional to 1/(x² + z²): the anomaly of a thin vertical dike, magnetized vertically, whose top is at depth z. For this curve the half-width at half maximum equals z, and the Peters half-slope distance d is about 1.2z.

  • Section 2 draws one fixed curve without a distance scale, so it shows the construction only.
  • Section 3 uses one induced point dipole (a sphere) on a south–north profile. The reduced-to-pole curve is that body's anomaly computed directly at I = 90°, an ideal RTP result without the instability or remanence errors a real filter can have.
