Explain
Which property of the formation does each log respond to, and why does that decide which tracks react to a change of pore fluid?
Gamma ray (API) Resistivity (Ω·m, log) Neutron porosity (%, limestone units) Bulk density (g/cc)
Assign a lithology and thickness to each of five intervals. Curves update instantly. On the shared neutron-density track, shale shows separation (neutron left of density), water-filled limestone overlays, and gas sand shows crossover (neutron right of density).
Model assumptionsWhat this simulation simplifies
  • Each lithology carries one fixed set of typical, noise-free values (GR, resistivity, NPHI, RHOB), so every curve is a blocky step; thickness moves the steps but never changes the values, with no vertical-resolution or shoulder-bed averaging.
  • Porosity and pore fluid are fixed inside each lithology (for example limestone at 5% porosity and clay till at 25%) and cannot be varied on their own.
  • Borehole size, mud, invasion, and tool standoff are ignored, and resistivity is a single value per layer with no shallow and deep readings.
  • NPHI is in limestone units on the shared track (45 to −15 %, with RHOB 1.95 to 2.95 g/cc); values beyond the scale, such as the 1.35 g/cc density of coal, sit on the track edge with an arrow.
